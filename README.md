# Shalini — Internship Portfolio

A responsive internship-focused portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Before publishing
1. Replace `your-email@example.com` with your real email.
2. Replace GitHub and LinkedIn links with your profiles.
3. Replace project GitHub/demo links with the actual URLs.
4. Add your resume as `resume.pdf` in this folder.
5. Review project descriptions so every claim is accurate.

## Deploy
This static site can be deployed using GitHub Pages, Netlify, or Vercel.
